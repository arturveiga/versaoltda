# Theme translations

The theme source language is Brazilian Portuguese (`pt_BR`). English front-end translations are stored in `en_US.l10n.php`, the PHP translation format supported by current WordPress versions.

The language switcher stores the selected locale in the `versao_ltda_locale` cookie. Theme strings and WooCommerce interface strings follow that locale.

Product names, product descriptions, page content, URLs, and media entered in WordPress are database content. Use Polylang for WooCommerce, WPML/WooCommerce Multilingual, or another WooCommerce-compatible multilingual plugin to maintain translated versions of that content in production.
