# Projeto Versão Ltda.

## Objetivo

Desenvolver um tema exclusivo para WooCommerce baseado no layout criado pelo designer.

## Tecnologias

- WordPress
- WooCommerce
- PHP 8.2
- CSS moderno
- JavaScript ES6
- HTML5

## Regras

- Não utilizar Elementor
- Não utilizar Bootstrap
- Não utilizar jQuery se não for necessário
- Código organizado em componentes
- CSS separado por módulos
- Responsivo
- SEO Friendly
- Performance

## Estrutura

Componentes reutilizáveis.

## Prioridade

1 Header

2 Home

3 Produto

4 Loja

5 Carrinho

6 Checkout

7 Minha Conta
